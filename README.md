# Student Grade Calculator

A beginner C program that calculates the total marks, average, and grade for 3 subjects.

## 🛠️ Language Used

- C

## 📚 What I Learned

- Variables
- `scanf()`
- `printf()`
- Arithmetic calculations
- `if`, `else if`, and `else`
- Basic C programming logic

## ▶️ How It Works

1. Enter marks for 3 subjects.
2. The program calculates the total.
3. It calculates the average.
4. It assigns a grade based on the average.

## 🎯 Purpose

This is one of my beginner programming projects while learning C as an EEE student.
